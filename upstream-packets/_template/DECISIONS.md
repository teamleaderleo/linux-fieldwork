## Required decision topics

Add entries when applicable for:

- one pull request versus an ordered series;
- composition versus split;
- selected implementation and rejected alternatives;
- canonical carrier and superseded predecessors;
- upstream destination and delivery method;
- compatibility policy;
- hold, retire, or reopen;
- external authorization and actual submission;
- public response that changes the candidate.

## Final disposition

State `READY FOR AUTHORIZATION`, `HOLD`, `SPLIT`, `RETIRED`, or `SENT`, the exact date, and the evidence supporting that disposition.
