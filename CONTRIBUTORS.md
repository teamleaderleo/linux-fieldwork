# Contributors

This repository is an internal research workspace owned by `teamleaderleo`.

Agents may contribute experimental code, tests, workflows, fixtures, instrumentation, and documentation in owned repositories and forks when relevant to the current investigation.

Research commits are not upstream submissions. The human owner decides what, if anything, is later prepared for a third-party project.

Avoid accidental third-party GitHub backlinks and do not contact upstream projects without explicit authorization.
